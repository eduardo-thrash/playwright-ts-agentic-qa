# Learning Rules

- AI concepts are taught before implementation.
- Programming basics are skipped unless needed.
- Playwright is the practical domain, not the primary subject.
- Each module finishes with a small exercise.
- Skills, Agents and MCP are explained before they are configured.
- Prefer one responsibility per Skill or Agent.
- Destructive actions require explicit approval.
- The repository is the source of truth.
- Markdown is canonical; PDF is optional as a snapshot.
