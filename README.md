# Agentic QA

Repositorio práctico y de aprendizaje para construir un flujo de QA Automation asistido por agentes.

## Objetivo

Aprender y aplicar:

- Fundamentos de AI / LLM
- Claude Code / Coding Agents
- Prompt Engineering
- Context Engineering
- Tools
- Skills
- Agents y Subagents
- MCP
- Playwright MCP
- Seguridad y autonomía
- Playwright + TypeScript
- playwright-bdd + Gherkin
- Allure Reports

## Fuente de verdad

El repositorio, no el historial de conversación.

Para continuar la ruta:

1. Lee `AGENTS.md`.
2. Revisa `docs/roadmap.md`.
3. Revisa `docs/progress.md`.
4. Continúa desde `Next lesson`.

## Automatización

La automatización vive en `src/`.

La configuración ejecutable principal vive en la raíz:
- `package.json`
- `playwright.config.ts`
- `tsconfig.json`
- `.env.example`
